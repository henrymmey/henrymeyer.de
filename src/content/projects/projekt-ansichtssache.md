## Overview

Projekt Ansichtssache is a student project by students of Gymnasium Oesede that aims to make the web more accessible. Its main project is an Accessibility Widget that helps users adapt websites to their individual needs.

## Projects

- **Accessibility Widget** — A browser-based accessibility panel with tools for reading, focus, display, motion, and other personal needs
- **Browser Extension** — The Accessibility Widget packaged for Chrome and Firefox
- **Preview Website** — An interactive website for exploring the widget's features
- **Project Website** — The public website and information hub for Projekt Ansichtssache

## What I Do

The project was started by friends of mine as a school project at Gymnasium Oesede, which I do not attend myself. They asked me to develop the first prototypes, which I built independently from the initial idea to working implementations.

Today, Anton and Raphael are taking over more of the Accessibility Widget's development while learning programming themselves. I continue to contribute in the background and maintain, manage, and coordinate the technical side of the project.

I maintain the browser extension, both websites, and the GitHub organization. This includes keeping the repositories organized, managing releases and deployments, reviewing changes, and making sure the different parts of the project work together.

## What I Learn

Projekt Ansichtssache gives me experience with the complete lifecycle of a real product: building prototypes, publishing software, maintaining multiple repositories, and supporting other developers as they take over parts of the codebase.

The project also teaches me how to share technical responsibility, explain code and workflows, and create a structure in which people with different levels of programming experience can contribute.
