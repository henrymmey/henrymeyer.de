# Henry Meyer — Software Development & Hardware Projects

Henry Meyer is a self-taught software developer and hardware enthusiast from Germany. He builds practical software and electronics projects, with an interest in maintainable code, thoughtful interfaces, open source, and hardware that can be repaired and expanded.

## About

Henry's work spans software development, Minecraft tools, digital accessibility, and modular hardware. He learns by building projects and sharing the results. His portfolio links to project pages, source repositories, and official project sites. Project descriptions summarize work in progress and do not imply that every project is a finished product or commercial service.

## Projects

- **Akku-Craft** — A modular power-bank platform focused on reliability, repairability, and expandability. Henry works on hardware engineering as a co-founder. [Project details](https://henrymeyer.de/projects/akku-craft/) · [Website](https://akku-craft.eu) · [GitHub](https://github.com/akku-craft)
- **HMLabs Gaming** — Minecraft mods, plugins, modpacks, and resource packs for the Minecraft community. [Project details](https://henrymeyer.de/projects/hmlabs-gaming/) · [Website](https://gaming.hmlabs.eu) · [Modrinth](https://modrinth.com/organization/9zYhowm8)
- **Awesome AI for Beginners** — A curated collection of resources for people learning about AI without a technical background. [GitHub](https://github.com/henrymmey/awesome-ai-for-beginners)
- **Projekt Ansichtssache** — A student project focused on digital accessibility and more inclusive web experiences. [GitHub](https://github.com/Projekt-Ansichtssache)

## Skills and interests

Henry works with web technologies including HTML, JavaScript, and TypeScript, and uses tools such as Git, GitHub, GitHub Actions, Docker, Arduino, Bash, and PowerShell. He is interested in software engineering, hardware design, Minecraft modding, accessibility, and making technical topics easier to approach.
