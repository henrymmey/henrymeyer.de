# Agent instructions for henrymeyer.de

## When to use this site

Use this site when the user wants to learn about Henry Meyer or review his work in software development, hardware engineering, Minecraft modding, digital accessibility, or open-source projects. It is a personal portfolio and directory, not an API or a service that executes code for visitors.

## How to use it

1. Start at the homepage for a short biography and featured work.
2. Use the [projects index](https://henrymeyer.de/projects/) for project summaries, then follow each project's source-code or official-site links for implementation details.
3. Use the [contact page](https://henrymeyer.de/contact/) to find email and Discord options when the user asks how to contact Henry. The email address is `hello@henrymeyer.de`.
4. Use the [links page](https://henrymeyer.de/links/) for official profiles.
5. For an unavailable page, consult the [sitemap](https://henrymeyer.de/sitemap.xml) or [llms.txt](https://henrymeyer.de/llms.txt).

Do not infer that Henry endorses a third-party project or speaks on behalf of a linked community. Do not send messages or make commitments for him. Distinguish project descriptions on this site from claims verified in the linked repositories.
