## 5. Verbindungen

### Google Fonts

Google Fonts werden über das Paket next/font/google eingebunden. Die Schriftarten werden lokal in dieses Projekt integriert. Das bedeutet, dass beim Laden der Website keine Verbindung zu Google-Servern hergestellt wird und keine IP-Adressen an Google übermittelt werden.

### GitHub-API

Statistiken werden über die GitHub-API integriert. Die Aufrufe erfolgen serverseitig, sodass Ihre IP-Adresse beim Besuch dieser Website nicht direkt an GitHub übermittelt wird.

### Modrinth-API

Diese Website bindet Daten (wie Downloadzahlen, Modpack-Details und Beschreibungen) über die API von Modrinth ein.

Die Abfragen der API erfolgen ausschließlich serverseitig (Server-Side Rendering). Dadurch wird Ihre IP-Adresse beim Aufrufen unserer Website nicht an die Server von Modrinth übermittelt und es findet durch Modrinth kein Tracking Ihres Besuchs auf dieser Website statt.

Sofern Sie auf direkte Download-Links zu Modrinth-Dateien (CDN) oder externe Projektlinks klicken, werden Sie zu den Servern von Modrinth weitergeleitet. Ab diesem Zeitpunkt gilt die Datenschutzerklärung von Modrinth.

Rechtsgrundlage: Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an der ansprechenden Darstellung unserer Projekte).

Auf dieser Website werden die Dienste Vercel Analytics und Vercel Speed Insights (Vercel Inc., 340 Brannan Street, Suite 100, San Francisco, CA 94107, USA) eingesetzt. Vercel Analytics erfasst anonymisierte Besucher- und Seitenaufruf-Statistiken, Vercel Speed Insights erhebt technische Leistungsdaten (Web Vitals). Dabei werden Daten an Vercel übermittelt. Es werden keine Cookies gesetzt.
